# NASDAQ Cosmos

Live NASDAQ trades (AAPL, NVDA, TSLA, MSFT, AMZN) rendered as comets pulled by the gravity of five stars.
Data: Finnhub WebSocket. A default API key is embedded (published with the owner's consent) so the page connects on open; it can be replaced via the settings panel.
Open with `#demo` for a simulated feed.
